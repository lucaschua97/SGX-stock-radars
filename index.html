❓ How the SGX Buy Radar works

1. Watchlist: Add or remove SGX stocks. The list is saved in this browser.

2. Quotes: The browser calls your Cloudflare Worker, which retrieves market data and returns it to the dashboard.

3. Quote timestamp: “Quote data updated” is when the API returned quote data. It is not a market-open signal and does not mean a recommendation was recalculated.

4. Missing price: “⚠ DATA UNAVAILABLE” means the upstream provider did not return a usable price for that symbol. The site will not invent one.

5. Events: A separate event feed should provide earnings, dividend announcement/ex-dividend/payment dates and an “Events updated” timestamp.

6. Analysis: A separate analysis engine should combine price/trend, valuation, earnings, dividends and news to produce BUY / WAIT / HOLD / AVOID, with Buy Range, Lock-in Price, reasons and an “Analysis updated” timestamp.

7. Refresh: Use ↻ Refresh for an immediate quote request. Automatic quote refresh runs every 2 minutes.

Current V12 status: Watchlist, themes, Cloudflare quote connection, quote timestamp, automatic refresh and missing-data handling are implemented. Multi-provider fallback, event data and the dynamic BUY/WAIT/HOLD engine require backend endpoints to be added to the Cloudflare Worker.
