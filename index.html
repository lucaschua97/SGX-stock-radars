🧠 How the price targets work

Important: the buy range and lock-in prices are not yet AI-auto-updated in this V10 client. They are stored as strategy inputs so the dashboard never silently changes your targets.

For a genuinely adaptive system, the next layer should recalculate targets from fresh price, earnings, dividend, valuation and news data, then show why a target changed and require your approval before saving it.

Recommended: refresh market data frequently, but update investment targets only after an evidence-based analysis cycle.
Yahoo SGX quotes are delayed. This is a monitoring/decision-support dashboard, not an execution system. Do not put private API keys in public HTML.
